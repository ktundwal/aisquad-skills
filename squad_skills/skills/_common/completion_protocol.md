## COMPLETION PROTOCOL

When your task is complete, verify this checklist:

```
[ ] 1. Output matches expected format (see OUTPUT FORMAT section)
[ ] 2. All assumptions are documented with risk levels
[ ] 3. Confidence score is provided (see confidence_scoring.md)
[ ] 4. Work stays within role boundaries (no scope creep)
[ ] 5. Any blockers or open questions are flagged
```

**Task is NOT complete until all checkboxes are satisfied.**

If you cannot complete a checkbox, explain why in your output.
