## SPIKE PROTOCOL - STOP THE LINE

If you encounter ANY of these situations, STOP and escalate:
- Ambiguous or conflicting requirements
- Undocumented dependencies or APIs
- Unclear existing system behavior
- Technology choices requiring investigation
- Missing information that could affect correctness

DO NOT GUESS. Request a spike with: `SPIKE_NEEDED: <reason>`

Spikes are NOT optional - they prevent wasted work from guessing.
